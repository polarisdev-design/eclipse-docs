ECLIPSE DOCUMENTATION SETUP

1. Clone your eclipse-docs repository with GitHub Desktop.
2. Extract this ZIP into that repository folder.
   Put package.json, docs and .github directly in the repository root.
   Do not create another eclipse-docs folder inside the repository.
3. Open the repository folder in VS Code.
4. Install Node.js 22 or newer from https://nodejs.org if needed.
5. Open Terminal > New Terminal. Confirm it is in the folder containing package.json.
6. Run this command:

npm.cmd ci

7. Run this command to preview:

npm.cmd run docs:dev

8. Open the complete localhost URL printed in the terminal. Ctrl+C stops the server.
9. On GitHub, open repository Settings > Pages.
10. Set Build and deployment > Source to GitHub Actions.
11. In GitHub Desktop, commit the files to main and click Push origin.
12. Check the Deploy Eclipse docs workflow in the repository's Actions tab.
13. After it succeeds, Settings > Pages shows the website link.

The workflow detects the Pages base path automatically. No username edit is required.
If your default branch is not main, change branches in .github/workflows/deploy.yml.

Write guides in docs. Change navigation in docs/.vitepress/config.mts.
See README.md for the folder map and production build command.
